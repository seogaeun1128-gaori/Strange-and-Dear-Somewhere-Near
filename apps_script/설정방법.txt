구글 드라이브 자동 업로드 설정 방법 (처음 한 번만)

1. 구글 드라이브에서 콜라주를 모을 폴더를 만듭니다.
   폴더를 열면 주소창이 https://drive.google.com/drive/folders/XXXXXXXX 형태인데,
   맨 끝의 XXXXXXXX 가 폴더 ID 입니다.

2. https://script.google.com 에 접속해 [새 프로젝트]를 만듭니다.
   기본 코드를 모두 지우고 이 폴더의 Code.gs 내용을 붙여넣습니다.
   FOLDER_ID 의 '여기에_드라이브_폴더_ID' 를 1번의 폴더 ID 로 바꾸고 저장합니다.
   ※ 폴더 ID 는 Apps Script 에만 넣고, GitHub 에 올리는 파일에는 넣지 마세요.

3. 위쪽 함수 선택 칸에서 testFolder 를 고르고 [실행]을 누릅니다.
   권한 승인 창이 뜨면 본인 계정으로 허용합니다.
   ('확인되지 않은 앱' 경고가 나오면 [고급] → [이동]을 누르면 됩니다. 본인이 만든 스크립트라 괜찮습니다.)
   실행 로그에 폴더 이름이 나오면 성공입니다.

4. 오른쪽 위 [배포] → [새 배포] → 유형: [웹 앱]
   - 다음 사용자 인증 정보로 실행: 나
   - 액세스 권한이 있는 사용자: 모든 사용자
   [배포]를 누르면 나오는 웹 앱 URL(https://script.google.com/macros/s/.../exec)을 복사합니다.

5. 이 URL 을 Claude 에게 알려주거나, index.html 의 DRIVE_UPLOAD_URL = '' 따옴표 안에 붙여넣고 push 합니다.

※ Code.gs 를 나중에 수정했다면 [배포] → [배포 관리] → 연필 아이콘 → 버전: [새 버전] 으로 다시 배포해야 반영됩니다.
